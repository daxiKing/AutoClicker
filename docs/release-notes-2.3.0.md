# AutoClicker v2.3.0 — Atlas

A retro Windows 95/98-style automation console for Windows and Linux.

## Highlights

- **Discord Rich Presence** — publishes the live engine state, session timer and a
  GitHub link through Discord's local IPC socket using AutoClicker's own public client.
- **Explore tab** — browse Steam Specials, top sellers, new releases and coming-soon
  games with discount badges, USD prices and one-click store links.
- **Connections** — toggle Rich Presence, link a public Steam community profile and
  link the GitHub repository used by the updater.
- **GitHub auto-updates** — compares the installed build with the newest public
  release, downloads the installer into Downloads and checks quietly on startup.
- **43 interface languages** — persisted language picker with English fallback.
- **Linux support** — pynput X11/Wayland input backend, platform-aware settings, a
  `.desktop` entry and CI packages for Windows and Linux.
- **Panic overlay fixed** — the red flash now uses a real Qt fade animation.
- All v2.2.0 image-targeting, color-matching, macro and click-engine features remain.
