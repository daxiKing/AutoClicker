## AutoClicker v2.4.0 — Nebula is out now

AutoClicker v2.4.0 "Nebula" is now available on itch.io for Windows and Linux.

### What's new in 2.4.0

- **1000× better everything** — rebuilt click-engine pacing, smoother auto-key timing, tighter macro playback, and faster image-target scans on Windows and Linux
- **Discord Rich Presence** — publishes the live engine state, session timer and a GitHub link through Discord's local IPC socket using AutoClicker's own public client ID
- **Explore tab** — browse Steam Specials, top sellers, new releases and coming-soon games with discount badges, USD prices and one-click store links
- **Connections** — toggle Rich Presence, link a public Steam community profile (no password), and link the GitHub repository used by the updater
- **GitHub auto-updates** — compares your installed build with the newest public release and downloads the installer into Downloads
- **43 interface languages** — persisted language picker with English fallback
- **Linux support** — pynput X11/Wayland input backend, platform-aware settings, `.desktop` entry and CI packages
- **Discord IPC fixed** — Rich Presence now connects reliably through the native asyncio named-pipe transport
- **Panic overlay fixed** — the red flash now fades through a real Qt animation

### Install

Grab the installer from the download section below, or if you already have AutoClicker installed through the itch.io app, it will offer the update automatically.

Legitimate automation only. AutoClicker sends synthetic input and matches pixels on your own screen; it does not read game memory, bypass anti-cheat, or implement aimbots, aim assist or wallhacks.
